# v0

商业机制研究系统的v0版本，提供研究者与独立质疑者协作的本地研究流程。

- 支持只读业务SQLite与隔离Python分析，批量查询结果落盘和分页。
- 保存原始预测、反证、质疑与修订；审查草稿可显式修补并幂等提交。
- 支持活跃假说管理、未决终结、阶段报告、协作暂停与有界恢复。
- 提供后台运行监督、显式副本迁移、安装预检和整体更新适配检查。
- 修复质疑者错误引用反馈时使用错误投影表导致的退出。

发行内容为源码、CLI/Python API、必要文档、测试、合成样例、部署工具及验证摘要。运行工作区、真实数据、模型配置/密钥、私有对话、内部实验报告、理论草稿和未采用原型不在发行内容中。

Python包版本为`0.0.0`，Git标签与GitHub版本名称均为`v0`。

当前Linux本地工程检查通过，macOS结果以对应提交的CI为准。工程验收覆盖实际图调度、隔离、两角色工具、报告归档和恢复，外部模型调用为0。详细计数见[验证摘要](../../verification/v0.json)和[部署验证](../../DEPLOYMENT_VERIFICATION.md)。

研究质量仍需人工复核：指标方向、汇总口径、原预测与goal一致性、后续复核委托可能存在缺口。接受/反驳标签与报告数量不构成机制正确性证明。连续24小时可用性尚未认证，见[评价范围](../EVALUATION.md)。
